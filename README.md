# Server Health API

A lightweight REST API built with **FastAPI** to monitor the health status of Spring Boot applications through Actuator endpoints.

The API checks both:

* **Liveness** (`/actuator/health/liveness`)
* **Readiness** (`/actuator/health/readiness`)

and returns a consolidated server status (`UP` or `DOWN`) along with HTTP response information and response times.

## Features

* Monitor one or multiple servers in a single request
* Spring Boot Actuator health checks
* Liveness and Readiness validation
* HTTP response time measurement
* Error handling (timeouts, DNS failures, connection errors)
* Swagger/OpenAPI documentation automatically generated by FastAPI
* JSON-based REST API
* Lightweight and easy to deploy

## Technologies

* Python 3.x
* FastAPI
* Requests
* Uvicorn

## API Endpoint

```http
GET /ServerHealthAPI
```

### Example Request

```http
GET /ServerHealthAPI?servers=https://server1.example.com&servers=https://server2.example.com
```

### Example Response

```json
[
  {
    "Serveur": "server1.example.com",
    "Statut": "UP",
    "Liveness": {
      "up": true,
      "status_code": 200,
      "response_time_ms": 75
    },
    "Readiness": {
      "up": true,
      "status_code": 200,
      "response_time_ms": 62
    },
    "Heure": "2026-06-10 12:45:00"
  }
]
```

## Running the Application

Install dependencies:

```bash
pip install fastapi uvicorn requests
```

Start the API server:

```bash
python -m uvicorn ServerHealthAPI:app --reload
```

Access Swagger UI:

```text
http://localhost:8000/docs
```

## Use Cases

* Application health monitoring
* Spring Boot environment validation
* DevOps and operational checks
* CI/CD pipeline verification
* Production readiness monitoring
